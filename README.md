# 🌱 Green Champion Scoring & Employee Audit System (ระบบนับคะแนนและตรวจสอบพนักงาน)

ระบบตัดสินและนับคะแนนการแข่งขันโครงการ **Green Champion** ประจำปี ระหว่าง 6 หน่วยงาน: **ปผ., ปอ., คจ., ปต., ปก., ปล.**  
รอบการสะสมคะแนน: **เดือนกุมภาพันธ์ ถึง 5 พฤศจิกายน**

---

## 👥 ฐานข้อมูลพนักงานจริงทั้ง 6 หน่วยงาน (รวม 224 คน)
ระบบได้นำเข้ารายชื่อพนักงานจริงทั้งหมด 224 คน เพื่อใช้ตรวจสอบความครบถ้วนในการเข้าร่วมกิจกรรม:
- **ปผ.** : 66 คน
- **ปล.** : 41 คน
- **ปอ.** : 33 คน
- **ปต.** : 33 คน
- **ปก.** : 28 คน
- **คจ.** : 23 คน
- **รวมทั้งสิ้น:** **224 คน**

---

## 📋 ระบบตรวจสอบรายชื่อพนักงาน & เช็คชื่อการเข้าร่วม (Employee Checklist & Attendance)
เครื่องมือตรวจสอบรายบุคคลเพื่อติดตามการมีส่วนร่วมของพนักงานในแต่ละเดือน:
1. **การ์ดสรุปสถิติประจำเดือน (Participation Summary Card)**:
   - แสดงข้อมูลหน่วยงาน เดือนที่เลือก และจำนวนพนักงานในสังกัดจริง
   - สรุปตัวเลข 4 ช่อง: พนักงานสังกัดจริง, เข้าร่วมแล้ว, ยังไม่เข้าร่วม (คน), และอัตราการมีส่วนร่วม (%) (แสดงสถิติจริงอย่างเป็นกลาง ไม่ตัดสินเป็นแบบสถานะผ่าน/ตก)
2. **ตัวกรอง 3 มุมมอง (Quick Filter Tabs)**:
   - `👥 ทั้งหมด (N คน)`: แสดงพนักงานทั้งหมดในแผนก
   - `✅ เข้าร่วมแล้ว (N คน)`: แสดงเฉพาะคนที่เข้าร่วมแล้ว
   - `⏳ ยังไม่เข้าร่วม (N คน)`: กรองแสดงเฉพาะคนที่ยังไม่ได้เข้าร่วมทันที ช่วยให้หัวหน้า/Admin ติดตามได้ตรงตัวคน
3. **ช่องค้นหา (Search Box)**: ค้นหาด้วยรหัสพนักงาน (เช่น `410056`), ชื่อ-นามสกุล หรือตำแหน่ง
4. **ฟังก์ชันสำหรับ Admin**:
   - ติ๊กถูก `[✓]` หน้าชื่อเพื่อเปลี่ยนการเข้าร่วม
   - ปุ่ม `✅ เช็คทุกคน (100%)`: ติ๊กทุกคนในคลิกเดียว
   - ปุ่ม `🔄 ล้างการเลือก`: รีเซ็ตสถานะ
   - ปุ่ม `💾 บันทึกผลการเช็คชื่อ`: บันทึกข้อมูลและซิงก์คะแนนเข้าสู่ระบบ Green Champion อัตโนมัติ

---

## 🏆 3 รางวัลใหญ่ประจำโครงการ
1. **Green Champion Award**: หน่วยงานคะแนนสูงสุด 3 อันดับแรก (จากเกณฑ์ 12 ข้อ)
2. **Green Champs Crew**: พนักงานในหน่วยงานมีส่วนร่วมสูงสุด (คำนวณจากยอดเข้าร่วมจริงเทียบพนักงาน 224 คน)
3. **Green Sharing Champion**: ผลงานแบ่งปันความรู้สูงสุด (ข้อ 2 ENV Sharing + ข้อ 3 KM Portal + ข้อ 4 OpEx Portal)

---

## 📋 เกณฑ์การให้คะแนน 12 ข้อ
1. **ENV Report**: 1,000 คะแนน/เดือน
2. **ENV Sharing**: 200 คะแนน/เดือน
3. **KM Portal**: 200 คะแนน/เดือน
4. **OpEx Portal**: 500 คะแนน/เดือน
5. **ทำ PR ส่ง ปภ.**: 50 คะแนน/เดือน
6. **ENV Substandard**: 10 คะแนน/ครั้ง
7. **ไม่เกิด Accident**: 50 คะแนน/เดือน
8. **ไม่เกิด NCR**: 50 คะแนน/เดือน
9. **ไม่เกิด Abnormal**: 50 คะแนน/เดือน
10. **Triple Zero Combo (Acc + NCR + Abn)**: 150 คะแนน/เดือน *(ระบบติ๊กให้อัตโนมัติ)*
11. **ลดของเสียหรือน้ำเสีย**: 1 คะแนน / 1 ลบ.ม.
12. **Green Idea**: 500 คะแนน / เรื่อง
